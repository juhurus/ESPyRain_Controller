# ESPHome Sprinkler Controller for Home Assistant

This repository contains a packaged Home Assistant + ESPHome sprinkler controller system.

## Included
- `ESP_sprinkler-controller/` - ESPHome package and wrapper examples
- `packages/` - Home Assistant package entrypoint
- `package_sources/` - Home Assistant package source files
- `HA_dashboard/` - optional dashboard YAML and dependency notes
- `INSTALL_CHECKLIST.md` - install and setup checklist

## Start Here
1. Read `INSTALL_CHECKLIST.md`
2. Review `ESP_sprinkler-controller/README.md`
3. Review `HA_dashboard/README.md`

## Notes
- Local secrets and private machine-specific files are intentionally excluded from this publish copy.
- `VERSION` is the canonical project version source.
